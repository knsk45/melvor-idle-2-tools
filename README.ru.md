# Melvor Idle 2 Tools

Неофициальные калькуляторы Melvor Idle 2. Основной язык — английский; русский доступен переключателем.

Из запущенного демо v0.11.2-alpha.4 (Steam build26074343) проверены6деревьев и3куста. База содержит уровни, здоровье, интервал удара, базовый XP, количество основной добычи и цену. [Протокол](docs/DEMO_OBSERVATION_20261024.md).

Базовый режим: урон1заудар, без бонусов. Полный сруб = здоровье × интервал удара. Normal Tree:3с/сруб →1200брёвен/ч,3600XP/ч,3600GPвыручки/ч. Побочные предметы исключены. Активные бонусы сохранения и условная сверка с панелью игры описаны отдельно; автоматического применения неподтверждённых бонусов нет.

Ручной режим принимает итоговые значения за полный сруб, а не за удар. Уровень, канал/build, поиск, сортировка, цели и сохранение настроек поддерживаются. Проверенные данные относятся только к этой сборке демо.

Node22.12+/pnpm11: pnpm install --frozen-lockfile, pnpm dev, pnpm check. Локально: http://127.0.0.1:5173/melvor-idle-2-tools/ . GitHub Pages не опубликован; запуск только вручную по отдельному поручению.
