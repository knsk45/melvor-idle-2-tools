# Melvor Idle 2 Tools

Неофициальный справочник базовой эффективности Melvor Idle 2. Основной язык — английский, русский включается переключателем.

Калькулятор удалён: нет параметров персонажа, целей и настройки бонусов. Внутри навыка действия сортируются по опыту, основной добыче и выручке за игровой час. Показатели заранее подготовлены по базовым параметрам игры.

Готовы таблицы рубки (9 обычных действий демо), рыбалки (11), добычи руды (14), производственных навыков, Farming, Thieving, Hunting и Ranching. Всего 16 разделов имеют фиксированные таблицы; ещё 9 разделов ожидают проверки или зависят от сценария. Все 25 навыков есть в навигации. Заблокированные и условные определения доступны отдельным фильтром.

Рыбалка учитывает мусор и последовательные дополнительные броски. Добыча руды учитывает накопление прогресса до гарантированного разрушения. Выручка включает прямую продажу побочной добычи, без вскрытия контейнеров; расходы не вычитаются. Основные предметы считаются отдельно.

Источник: v0.11.2-alpha.4 / Steam build 26074343. [Формулы и доказательства](docs/BASE_SKILL_FORMULAS.md), [основной README и запуск](README.md), [план](docs/ROADMAP.md). Сайт опубликован: https://knsk45.github.io/melvor-idle-2-tools/ . Обновления main публикуются после проверок.

Ограничения оставшихся навыков и правила baseline описаны в [статусе покрытия](docs/REMAINING_SKILLS_STATUS.md).

Главная страница — база всех 155 определений монстров проверенной демо-сборки: поиск по монстру, локации и добыче; фильтры по стилю, месту и блокировке; раскрывающиеся характеристики, добыча, атаки и эффекты. Полнота относится к реестру Enemy этой сборки, а не ко всей будущей игре или доказанной доступности в демо.

Боевые расчёты отложены по решению владельца; пример Golbin убран из интерфейса. В базе нет параметров персонажа и рейтингов боевой эффективности. [Методика базы](docs/MONSTER_DATABASE.md).
