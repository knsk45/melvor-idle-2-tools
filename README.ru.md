# Melvor Idle 2 Tools

Неофициальный справочник базовой эффективности Melvor Idle 2. Основной язык — английский, русский включается переключателем.

Калькулятор удалён: нет параметров персонажа, целей и настройки бонусов. Внутри навыка действия сортируются по опыту, основной добыче и выручке за игровой час. Показатели заранее подготовлены по базовым параметрам игры.

Готовы рубка (9 обычных действий демо), рыбалка (11) и добыча руды (14). Все 25 навыков есть в навигации; оставшиеся 22 раздела ожидают проверки механик. Заблокированные и условные определения доступны отдельным фильтром.

Рыбалка учитывает мусор и последовательные дополнительные броски. Добыча руды учитывает накопление прогресса до гарантированного разрушения. Выручка включает прямую продажу побочной добычи, без вскрытия контейнеров; расходы не вычитаются. Основные предметы считаются отдельно.
