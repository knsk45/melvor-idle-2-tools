# Melvor Idle 2 Tools

Unofficial, open-source Melvor Idle 2 reference and skill calculators. React + TypeScript + Vite, RU/EN, no account or backend.

Woodcutting MVP includes verified-data filters and numeric sorting, channel/build selection, skill level, manual effective-value calculations, quantity targets and versioned local settings. **The verified game dataset is empty.** Synthetic examples live only in tests. First-game values are never reused as sequel facts.

Use Node.js 22.12+ and pnpm 11: run `pnpm install --frozen-lockfile`, `pnpm dev`, then visit http://127.0.0.1:5173/melvor-idle-2-tools/ . Run `pnpm check` for lint, tests, types and production build.

Pages is not published. Deployment is manual, main-only and requires an explicit owner request. See [methodology](docs/METHODOLOGY.md), [sources](docs/SOURCES.md), [contributing](CONTRIBUTING.md) and [roadmap](docs/ROADMAP.md).
