# Методика

Для независимых повторяемых действий с постоянным эффективным интервалом t > 0: actions/h = 3600/t; XP/h = actions/h × XP/action; items/h = actions/h × expected items/action; gross GP/h = items/h × sell price. Expected seconds = target/items per hour × 3600.

Промежуточные вычисления не округляются, только отображение до двух знаков. Это долгосрочное ожидание, не гарантия времени случайной добычи. Не учитываются вторичные предметы, расходы, простои, время переключения и офлайн-лимиты. Выручка — не прибыль.

Ручной режим принимает уже эффективные значения: порядок бонусов не предполагается. Базовый режим не использует ручные поля. Неизвестное = null, нулевая цена допустима, невалидный интервал отклоняется. Неконечные результаты отклоняются.

Канал и build сравниваются точно; пустой build не даёт рекомендаций. В таблицу попадают только verified с источником и датой. Пока набор пуст, победитель отсутствует. При неполном наборе сравнение следует описывать как «лучшее среди проверенных».

localStorage: ключ melvor2.settings.v1, schemaVersion=1; повреждённая/неизвестная версия восстанавливает defaults, неподходящие поля игнорируются. Блокировка storage не мешает расчёту, показывается сообщение.
