# Modifiers: planned article

The base reference deliberately has no modifier controls or character calculator. This page is an editorial plan, not a verified equipment guide.

A future article will explain sources of speed, quantity and XP improvements, with build-specific evidence for each claim. Topics include tool intervals, wood damage, mining prospecting and shatter, fishing bait and priority selection, extra rolls and doubling. Additive/multiplicative stacking, caps, rounding and unlock conditions must be checked against the relevant game methods before publication.

Keep example improvements and progression advice separate from the fixed base tables. Do not infer modified rates from a save or import first-game mechanics. No modifiers are currently applied to the reference.
