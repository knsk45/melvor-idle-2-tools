# Agility: статус проверки

В пакете демо найден компонент навыка Agility, но не найдено ни одной доступной записи курса, локации или препятствия, из которой можно построить базовое действие. Навык остаётся в навигации как запланированный.

После появления таких записей таблица будет использовать общий сценарный слой: курс, препятствие, время, XP, стоимость и условия. До этого раздел не получает искусственных строк и рейтингов.
